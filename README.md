# Nexus Deportivo

Tournament-management platform built with a microservices architecture.

Repository name: `proyecto-microservicios`

## Technologies

- Java
- Spring Boot
- Maven
- JavaFX

## How to run it

1. Start all the microservices first:
   - `ms-deporte`
   - `ms-equipo`
   - `ms-historial`
   - `ms-multimedia`
   - `ms-partido`
   - `ms-torneo`
   - `ms-usuario`
2. Then run `ProyectosEclipse`, the main program.
